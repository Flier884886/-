# 微信状态媒体拉取工具

> 一键把微信好友状态里的图片/视频缓存拉到电脑，自动补全扩展名，随看随存。

## 简介

这是一个通过 ADB 连接安卓手机，从微信状态缓存目录中拉取媒体文件到电脑的小工具。拉取后会自动为没有扩展名的缓存文件补全扩展名（图片/视频），方便直接查看。也可以选择在导出完成后删除手机端的状态缓存。

同时，工具也支持对已经导出到电脑、但没有扩展名的媒体缓存进行批量自动补全扩展名。

它能较好地解决“微信好友状态里的图片/视频无法另存为”的痛点——看到好看的风景图，不必再厚着脸皮去问对方要（不太熟的话真的会很尴尬）。

> 一定只能是风景图吗？[doge]

## 功能特性

- 通过 ADB 从安卓手机拉取微信状态缓存的媒体文件
- 自动识别文件类型并补全扩展名（图片 / 视频）
- 可选：导出完成后删除手机端的状态缓存
- 支持对本地已导出的无扩展名媒体缓存批量补全扩展名
- 纯 Windows 平台适配，开箱即用（需自行配置 ADB）

## 不足

- 对于状态附带的表情包、文本、状态名称、发布者目前都无法另存为

## 适用平台

- 仅支持安卓手机
- 苹果手机或将永不支持
- 仅适配 Windows 平台，其他平台暂不适配
- 未来可能会推出 C++ 版本，届时跨平台将很容易实现

## 环境要求

- Windows 系统
- 安卓手机，并已开启 USB 调试
- ADB 工具需自行配置（本项目不集成 ADB）

> 关于 ADB 的安装与连接方法，请小白自行查找教程，此处不予赘述。

## 使用方法

### 1. 配置 ADB

确保 `adb` 已加入系统环境变量，或在终端中能直接调用。连接手机后可通过以下命令验证：

    adb devices

能正常列出设备即表示连接成功。

### 2. 拉取微信状态媒体

运行工具，按提示操作即可。工具会：

1. 通过 ADB 访问手机端微信状态缓存目录
2. 将媒体文件拉取到电脑指定目录
3. 自动为无扩展名的文件补全扩展名
4. 可选：删除手机端对应的状态缓存

### 3. 本地批量补全扩展名

如果之前已经导出过一批没有扩展名的媒体缓存，也可以直接使用本工具对本地目录进行批量补全扩展名。

## 注意事项

- 视频文件建议在微信中完整观看一遍，否则可能出现只缓存了一半的情况，拉取到的视频也会不完整。
- 删除手机端缓存的操作不可恢复，请谨慎勾选。
- 本工具仅用于个人学习与方便自己查看缓存内容，请勿用于侵犯他人隐私或传播他人内容。
